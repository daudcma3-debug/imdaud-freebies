# Password managers for finance teams: 1Password vs Bitwarden

Paid vs free comparison · 28 Nov 2026 · By Abu Daud, CMA

Prices as of 28 Nov 2026, in US dollars, read on each vendor's official pricing page. Check the page before you buy; prices and plans change.

## Plans and prices

| | 1Password (paid) | Bitwarden (free + open source) |
|---|---|---|
| Main business plan | **Business: US$8.99 per user / month, billed yearly** (US$107.88 per user per year) | **Teams: US$4 per user / month, billed annually** |
| Small-team option | Teams Starter Pack: US$24.95 / month billed yearly, up to 10 people; up to 10 more seats at US$4.99 each (20 max) | Enterprise: US$6 per user / month, billed annually |
| Free option | 14-day free trial, no credit card | Free individual account (unlimited passwords and devices); free sharing with one other user |
| Open source | No | Yes: apps and server code are public on GitHub (GPL-3.0 / AGPL-3.0, with some enterprise code under the source-available Bitwarden License) |
| Hosting | Hosted by 1Password | Hosted by Bitwarden; self-hosting is an Enterprise feature for businesses |
| Team controls | SSO with Okta, Entra ID, OneLogin, Duo · Watchtower security alerts · role-based vault permissions | Teams: event and audit logs, SCIM provisioning, Directory Connector · Enterprise adds SSO, enterprise policies, granular access control |

## Who should pick which

- **1Password** fits teams that want polished apps, Watchtower alerts and SSO with no IT work.
- **Bitwarden** fits cost-conscious teams that value open code, or IT-led firms that want to self-host on the Enterprise plan.

## Password controls for finance teams (my CMA checklist)

1. Keep every shared login (bank portals, tax portals, payroll, ERP admin) in one team vault, never in WhatsApp or a spreadsheet.
2. Turn on two-step login (MFA) for every account that can move money.
3. Give access by role: AP staff see AP logins, not treasury.
4. Review the access log monthly for the bank and tax portal entries.
5. Leaver day: remove the person from the vault, then change every shared password they could see.
6. Never store card numbers or one-time codes in shared notes.
